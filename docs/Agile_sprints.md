# خطة الدورات البرمجية (Agile Sprint Plan) - منصة تفضّل

## Sprint 1: بناء النواة وقواعد النطاق (Core Domain Rules & Models)
- **قصة المستخدم 1.1 (المتاجر والمنتجات):** إنشاء نماذج النطاق `Shop` و `Product` وتطبيق قيد الرؤية الشرطية للمنتجات المعتمَدة فقط (`CON-01`) والربط الإجباري بمعرف المتجر (`CON-02`).
- **قصة المستخدم 1.2 (إدارة المخزون):** تطبيق قيد التحقق والخصم الفوري للمخزون ومنع تجاوز الكميات المتاحة (`CON-03`).
- **قصة المستخدم 1.3 (الشحنات والقيود):** إنشاء نموذج الشحنة `ShipmentOrder` وتطبيق حظر تعديل العنوان بعد الطلب (`CON-04`) وقيد صلاحية طلب الإرجاع للطلبات المستلَمة فقط (`CON-05`).

---

## Sprint 2: آلة الحالات وسجل التدقيق وإدارة الخدمات
- **قصة المستخدم 2.1 (مسار الحالة الصارم):** تطوير آلة حالات الشحنة السلسية ومنع الانتقالات العشوائية أو التراجعية غير القانونية (`CON-06`).
- **قصة المستخدم 2.2 (سجل التدقيق الأمني):** تطوير خدمة التدقيق `AuditService` المعتمدة على سلسلة التجزئة الشفافية والمترابطة (`CON-07`).
- **قصة المستخدم 2.3 (إدارة الخدمات والمحاكاة):** تطوير `CatalogService` و `OrderService` و `CartService` لربط السلة بالكتالوج وإصدار الشحنات آلياً.

---

## Sprint 3: واجهات المستخدم العربية والربط الشامل
- **قصة المستخدم 3.1 (واجهة التسوق الكتالوج):** بناء شاشة الكتالوج `HomeScreen` مع التصفية حسب الفئة والمتجر والبحث الفوري وإضافة المفضلة.
- **قصة المستخدم 3.2 (واجهة السلة والدفع):** بناء شاشة `CartCheckoutScreen` لتقسيم السلة آلياً حسب المتجر، وتخصيص الخصومات، والدفع وإصدار الشحنات.
- **قصة المستخدم 3.3 (واجهة البائع وإدارة الطلبات):** بناء شاشة `OrderDetailsScreen` لمتابعة الشحنات وتحديث الحالات والاحتساب المالي واقتطاع عمولة المنصة (15%).
- **قصة المستخدم 3.4 (لوحة التحكم والرقابة Ops):** بناء شاشة `AdminDashboardScreen` للاعتماد الفوري للمتاجر والمنتجات وبث سجل التدقيق الحي.
